# My Budget Tracker

This is my Budget Tracker project. I improved the design this week using only CSS.

## What I built
A clean page where you can see expenses in a table and add new ones using a form.

## What each part does

- **Color Palette**  
  I chose a soft blue and white theme. It looks clean and professional.

- **Typography**  
  I used Poppins for headings and Inter for the rest of the text. It makes the page easy to read.

- **Table & Form**  
  The table has a blue header, alternating row colors, and nice spacing.  
  The form inputs and button are styled to match the same look.

- **Box Model**  
  I used padding, margin, borders, and rounded corners so the heading, form, and table each look like separate cards.

## How to view
Just open `index.html` in your browser.
