SpendWise - Budget Tracker                                              

SpendWise is a web-based financial tracking and dashboard application designed to help users monitor their income, expenses, and budgets seamlessly in one place.

📁 Project Structure

The project consists of three core web files:

index.html: The main user interface featuring a dashboard layout, a navigation sidebar, overview metric cards, an interactive expense logging form, an expense history table, and an embedded budgeting tips video.

style.css: The stylesheet governing the layout, typography, responsive design rules, dark theme support, and card micro-interactions.

script.js: The script handling initial application variables, budget calculation logic, user prompts, console reporting, and form event handling.

Features

Dashboard Overview Grid: Displays financial metrics and category breakdowns (Food & Dining, Transport, Rent, Entertainment, Savings, and Utilities).

Responsive Sidebar & Layout: Uses a CSS Grid layout framework that adapts fluidly to mobile and desktop screens.

Dynamic Expense Form: Allows users to input new expenses with names, amounts, and categories.

Financial Calculations: Automatically computes remaining balances and budget utilization percentages.

Dark Theme Support: Automatically adjusts styling based on system color scheme preferences (prefers-color-scheme: dark).

Getting Started

To run or view this project locally:

Clone or download the repository files (index.html, style.css, script.js, and associated assets like image.png) into a single folder.

Open index.html in any modern web browser.

Open your browser's Developer Tools Console (F12 or right-click -> Inspect -> Console) to view runtime financial reports and interactive form logs generated by script.js.
